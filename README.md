В данном проекте использовался следующий стек технологий:

* React + React Router Dom + Redux Toolkit + Vite
* ESLint + Prettier
* TypeScript
* Для наглядной работы со стейт менеджером Redux пользуется json-server
* Для удобства запросов на сервер используется axios
* Для работы с формами используется formik, yup, react-text-mask
* Для назначения id используется uuid

Путь проверки выполнения задания предлагаю следующий:

Создаете папку в любой директории компьютера
Выгружаете в эту папку проект при помощи команды git clone https://github.com/dve1997/gross-market.git
Запускаете терминал в VS Code
Запускаете проект при помощи команды npm run dev
После запуска проекта запустятся два localhost-а на 5173 порту (app) и на 3001 порту (json-server).
